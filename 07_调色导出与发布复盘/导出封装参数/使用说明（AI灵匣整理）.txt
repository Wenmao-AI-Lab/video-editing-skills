【所属分类】调色导出与发布复盘
【技能名称】导出封装参数
【技能标识】export-preset
【依赖情况】🟢 零门槛

【功能描述】
按平台给导出参数（比例/分辨率/帧率/码率/格式），出一套可存导出预设，避免每次重设。

【核心能力拆解】
  · 把"导出封装参数"这一步从"凭感觉"变成"有标准、可复用、可批量"的流程
  · 产出的是"能直接照做的清单/方案/参数"，不是空话，你拿到就能执行
  · 全程零外部付费 API 依赖，纯提示词工作流，装好就能用、不报错

【详细概述】
导出错参数=白剪。本技能按平台给标准导出参数（见 references/export_presets.md）：抖音 9:16 1080p、小红书 3:4、B站 16:9，码率/格式统一 MP4 H.264。并提醒导出前校验（首尾无黑帧、无爆音、色彩保真）。

交付"导出参数表"+校验清单。你在剪映导出页照填，存预设下次一键。

【适用场景】
  · 个人创作者：想把"导出封装参数"标准化，不每次从头琢磨
  · 带货/种草团队：需要把这一步沉淀成 SOP，新人照做不出错
  · 矩阵号批量生产：同一步复用同一套参数/清单，保证多账号调性一致

【输入要求】
  · 给我：你的平台 / 账号定位 / 素材或脚本（越具体产出越准）
  · 格式：自然语言描述即可，无需专业术语，我帮你转成施工图纸

【3 步上手】
  ① 你发："抖音和小红书导出参数分别怎么设"
  ② 我产出：对应平台的清单 / 方案 / 参数表（见下方产出样例）
  ③ 你照做：在剪映或对应工具里按清单点一遍，3-10 分钟落地

【真实触发例句】（可直接复制发送）
  · 抖音和小红书导出参数分别怎么设
  · 给我一套各平台导出预设
  · 导出前要注意什么，列清单

【标准交付物】
  · 一份可直接照做的 导出封装参数 方案/清单（含参数、步骤、自检点）
  · 需要表格/模板的技能，已把 templates 打包进 ZIP（references/）
  · 若本技能产出可被 FFmpeg 自动剪辑线消费，已按"机器可读中间产物"格式标注，详见 08_自动剪辑与批量导出(FFmpeg)/方案→成片桥接器

【产出样例】
输出：
抖音 1080×1920 / 30fps / 12-16Mbps / MP4
小红书 1080×1440 / 30fps / 8-10Mbps / MP4
校验 无黑帧/无爆音/色保真

【附带的参考模板/清单】
  · references/export_presets.md（已打包进 ZIP，可直接调用）

【常见翻车点（避坑）】
  · 别跳步：先有"调色预设应用"的产出，再进下一步，否则后期返工
  · 别堆料：包装/转场/花字点到为止，服务内容不抢戏
  · 别信外部依赖：本技能不调用任何付费 API，参数照填即有效

【衔接配合】
  · 上游：调色预设应用
  · 下游：多平台发布适配
  · 剪映手动线：脚本分镜 → 工程初始化 → 素材粗剪 → 精剪卡点 → 音频 → 字幕包装 → 调色导出发布复盘
  · FFmpeg 自动执行线：方案产出 → 08_方案→成片桥接器(script_to_srt / storyboard_to_manifest / beatdetect / color_map) → 08_自动成片流水线 → 多平台成片

【为什么零依赖也能用】
  · 本包所有技能均为提示词工作流，靠 Agent 推理 + 你本地工具（剪映等）执行
  · 不绑定任何外部付费 API / 密钥接口，没有联网密钥也能跑，不会中途报错

【常见问题 FAQ】
  · Q：码率越高越好？ A：够清晰即可，过高平台压缩反损。
  · Q：4K 传吗？ A：B站可，其余 1080p 足。
