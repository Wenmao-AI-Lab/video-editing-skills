【所属分类】调色导出与发布复盘
【技能名称】多平台发布适配
【技能标识】multi-platform-publish
【依赖情况】🟢 零门槛

【功能描述】
按平台给发布适配（标题套路/标签数/封面要求/发布时间），出发布清单，一次拍摄多平台分发。

【核心能力拆解】
  · 把"多平台发布适配"这一步从"凭感觉"变成"有标准、可复用、可批量"的流程
  · 产出的是"能直接照做的清单/方案/参数"，不是空话，你拿到就能执行
  · 全程零外部付费 API 依赖，纯提示词工作流，装好就能用、不报错

【详细概述】
同一条片发 5 个平台，不能一个标题用到底。本技能按平台调性给发布方案：抖音短狠标题+5-8标签、小红书情绪+8-10标签、B站干货标题、视频号朋友语气。并给发布时间建议和引导文案（点赞/关注/评论）。

交付"多平台发布清单"（见 references/platform_checklist.md），你照填。和封面/标题技能配套。

【适用场景】
  · 个人创作者：想把"多平台发布适配"标准化，不每次从头琢磨
  · 带货/种草团队：需要把这一步沉淀成 SOP，新人照做不出错
  · 矩阵号批量生产：同一步复用同一套参数/清单，保证多账号调性一致

【输入要求】
  · 给我：你的平台 / 账号定位 / 素材或脚本（越具体产出越准）
  · 格式：自然语言描述即可，无需专业术语，我帮你转成施工图纸

【3 步上手】
  ① 你发："同一条片发抖音小红书B站，标题标签怎么改"
  ② 我产出：对应平台的清单 / 方案 / 参数表（见下方产出样例）
  ③ 你照做：在剪映或对应工具里按清单点一遍，3-10 分钟落地

【真实触发例句】（可直接复制发送）
  · 同一条片发抖音小红书B站，标题标签怎么改
  · 给我各平台发布时间和引导文案
  · 发布前自检清单

【标准交付物】
  · 一份可直接照做的 多平台发布适配 方案/清单（含参数、步骤、自检点）
  · 需要表格/模板的技能，已把 templates 打包进 ZIP（references/）
  · 若本技能产出可被 FFmpeg 自动剪辑线消费，已按"机器可读中间产物"格式标注，详见 08_自动剪辑与批量导出(FFmpeg)/方案→成片桥接器

输出：

小红书 标题"挖到宝了这耳机" 标签8个 午休发
自检 标题含热词/封面3秒懂/标签覆盖/引导到位

【附带的参考模板/清单】
  · references/platform_checklist.md（已打包进 ZIP，可直接调用）

【常见翻车点（避坑）】
  · 别跳步：先有"导出封装参数"的产出，再进下一步，否则后期返工
  · 别堆料：包装/转场/花字点到为止，服务内容不抢戏
  · 别信外部依赖：本技能不调用任何付费 API，参数照填即有效

【衔接配合】
  · 上游：导出封装参数
  · 下游：数据复盘优化
  · 剪映手动线：脚本分镜 → 工程初始化 → 素材粗剪 → 精剪卡点 → 音频 → 字幕包装 → 调色导出发布复盘
  · FFmpeg 自动执行线：方案产出 → 08_方案→成片桥接器(script_to_srt / storyboard_to_manifest / beatdetect / color_map) → 08_自动成片流水线 → 多平台成片

【为什么零依赖也能用】
  · 本包所有技能均为提示词工作流，靠 Agent 推理 + 你本地工具（剪映等）执行
  · 不绑定任何外部付费 API / 密钥接口，没有联网密钥也能跑，不会中途报错

【常见问题 FAQ】
  · Q：能一键发？ A：平台不支持，本技能给清单你分别发。
  · Q：标签怎么选？ A：品类+场景+人群三层覆盖。

【质量自检清单】（交付前逐项确认）
  □ 产出是否对应你给的平台/账号定位
  □ 参数/清单是否可直接照做（无外部付费依赖）
  □ 是否标注了衔接的上下游技能
  □ 是否保留了你的关键卖点/数据，未擅自删改
