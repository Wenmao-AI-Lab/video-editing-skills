【所属分类】自动剪辑与批量导出(FFmpeg)
【技能名称】自动字幕识别与烧录
【技能标识】ffmpeg-auto-subtitle
【依赖情况】🟡 需本地 FFmpeg；字幕识别可选 whisper（本地免费）

【功能描述】
把字幕硬烧进视频：可直接烧录你已有的 srt，也可用本地 whisper 免费识别配音自动生成字幕再烧录——静音刷也能看字。

【这是真·自动执行技能】
  · 和 01-07 类「出方案让你手动做」不同，本技能带 scripts/ 脚本，调用你本地 FFmpeg 直接产出成片文件
  · 纯本地运行，零外部付费 API / 密钥依赖；FFmpeg 免费开源，字幕识别可选本地 whisper（同样免费）

【核心能力拆解】
  · 把"自动字幕识别与烧录"从"人工点按钮"变成"一行命令自动出片"
  · 可批量、可串联（pipeline 技能），适合矩阵号/口播日更的重复劳动

【详细概述】
本技能附带 scripts/auto_subtitle.py，两种用法：

① 烧录已有字幕（--srt）：你手头有 srt（比如用原包「06 字幕生成」产出的文本自己对齐的，或剪映识别导出的），直接硬烧进视频，平台静音播放也带字。
② 语音识别生成（--transcribe）：调用本地 whisper 模型识别配音，自动出 srt 再烧录。whisper 是本地开源模型，完全免费、不需要任何 API 密钥，首次会自动下载模型。

字幕样式用 force_style 指定中文黑体（微软雅黑）+ 白字黑描边，任何背景都看得清。对应原工作流「06 字幕与画面包装」——把"出字幕文本"升级成"出带字幕的成片"。纯本地，零付费依赖。

【适用场景】
  · 口播/带货日更：素材拼成片 + 多平台导出，几分钟搞定
  · 混剪（用你自有/CC0 合规素材）：批量预处理拼接
  · 矩阵号：同一条片一键出全平台尺寸

【输入要求】
  · 你自己的素材（或 CC0 合规素材），本地路径
  · 一条命令 + 几个参数即可，无需剪辑软件界面

【3 步上手】
  ① 装好 FFmpeg 并加入 PATH（免费）
  ② 在技能目录运行：python scripts/auto_subtitle.py <参数>
  ③ 拿到输出成片，直接进入下一环节或发布

【真实触发例句】（可直接复制发送）
  · 把我这段口播视频的字幕（sub.srt）硬烧进去，静音也能看
  · 用本地 whisper 识别这段配音，自动生成字幕并烧录
  · 字幕字体用微软雅黑，白字黑边

【标准交付物】
  · 一条/多条处理好的成片文件（mp4）
  · scripts/ 下脚本已打包进 ZIP，可直接运行

【产出样例】
命令示例（烧录已有字幕）：
python scripts/auto_subtitle.py --input 成片.mp4 --output 带字幕.mp4 --srt sub.srt

命令示例（本地识别）：
python scripts/auto_subtitle.py --input 成片.mp4 --output 带字幕.mp4 --transcribe --model base

输出：带字幕.mp4（字幕已硬编码进画面）

【附带的脚本】

【常见翻车点（避坑）】
  · 先确认 ffmpeg 在 PATH：终端跑 ffmpeg -version 有输出才行
  · 素材务必是你自有/CC0 合规的，别用他人视频，避免侵权
  · 字幕识别首次会下载 whisper 模型，耐心等几分钟

【为什么零依赖也能用】
  · 只用 FFmpeg（免费开源）+ 可选本地 whisper（免费本地模型），不调用任何付费 API/密钥
  · 脚本带 ffmpeg 自动定位：找不到系统 ffmpeg 时尝试 imageio-ffmpeg 自带，最大限度开箱能跑

【常见问题 FAQ】
  · Q：识别要钱吗？ A：whisper 本地跑，免费，无需密钥；首次下载模型 base 约 140MB。
  · Q：中文识别准吗？ A：base 够用，要求高用 small/medium；可指定 --model。
  · Q：字幕文件编码？ A：srt 用 UTF-8，避免乱码。
  · Q：会覆盖原片吗？ A：输出到新文件，原片不动。

【质量自检清单】（交付前逐项确认）
  □ FFmpeg 是否已安装并在 PATH
  □ 输入的素材是否自有/合规
  □ 输出成片是否能正常播放（首尾无黑帧/爆音）
  □ 多平台导出比例是否正确（9:16/3:4/16:9/1:1）
