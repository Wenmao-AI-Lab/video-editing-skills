■ 第0章 三件事先搞清
  1. 它不是剪映插件，是"教 Agent 怎么帮你剪"的流程技能包
  2. 每个技能产"清单/方案/参数表"，你拿到照做，3-10 分钟落地
  3. 不调任何外部付费接口，没密钥也能跑、不会中途报错

■ 第0.5章 预期管理（必读，避免理解偏）
  本包分三类 + 一座桥：
  · 01-07 类 = 提示词工作流：Agent 产出「方案 + 参数 + 清单 + 照做步骤」。
  · 08 类 = FFmpeg 自动执行技能：调用你本地 FFmpeg 直接产出成片文件（拼接/调色/多平台导出/字幕烧录），
    是"真·自动出片"。
  · 09 类 = 剪映自动成片技能：调用 pyJianYingDraft 把同一份 manifest 转成剪映草稿工程，剪映打开即出片。
  · 08_方案→成片桥接器 = 连接层：把 01/03/04/07 的"人读方案"转成 08/09 共用的"机器可读文件（manifest.json）"。

  ✅ 01-07 能自动产出：脚本/分镜/口播稿/卡点表/衔接表/字幕文本/调色参数/导出参数/发布清单/复盘模板
  ✅ 08 能自动产出：拼接成片 / 烧录字幕成片 / 调色成片 / 多平台尺寸成片
  ✅ 09 能自动产出：剪映草稿工程（视频轨/字幕轨/音频轨自动铺好），剪映打开即见时间线
  ✅ 桥接器能把：口播稿→srt、粗剪清单→manifest、卡点→切点json、调色名→preset
  ❌ 仍然不能自动做：替你打开剪映在剪映里点按钮、真去网上下载别人视频、真生成封面图
    （封面图技能出的是"构图卡+标题文案"，真出图需你配图或用图片生成工具）
  ⚠️ 08 类需要：本地安装 FFmpeg（免费开源）并加入 PATH。
  ⚠️ 09 类需要：本地安装 pyJianYingDraft（免费开源，pip install 即可），仅用于生成草稿 JSON，不需剪映本体。
  ⚠️ 字幕识别（whisper）属于可选但未实测分支，推荐走桥接器把 01 口播稿转成 srt，准确率更高、无需下载模型。
  ⚠️ 顺序提醒：先按口播重音做粗卡点（第⑨技能节奏卡点），配乐定稿后若需严格踩鼓点，回第⑨技能微调一次。
  ⚠️ 使用边界：字幕烧录需要 srt 文件（口播稿转）或你提供文案；纯音乐无旁白时需先给文案。
  ⚠️ 素材来源：本包不下载他人视频，用「素材来源与合规获取」解决"素材从哪来"（平台素材库/CC0图库/自拍清单/学结构不搬运）。

■ 第3章 逐技能详解（定位/概述/触发话术/交付物/示例对话/FAQ/衔接）
  ── 1. 爆款选题与脚本生成 ──
  【所属分类】脚本分镜与文案策划
  【技能标识】script-topic-generator
  【一句话定位】基于品类/账号定位/对标爆款，生成可拍可剪的短视频选题与口播脚本（含黄金3秒钩子、卖点结构、转化收尾）。

  【详细概述】
    本技能帮你把"想做一条视频"变成"拿到就能拍的脚本"。输入你的品类、账号定位、想打的卖点或人设，它会先帮你做选题筛选（用爆款结构：痛点/好奇/反差/利益点开场），再产出 30 秒~3 分钟不等的口播脚本。
    产出不是空泛大纲，而是带【镜头/台词/字幕/时长】四列的逐镜脚本草稿，可直接交给"分镜脚本拆解"技能转成剪映时间线，或自己照着拍。
    适用：带货视频、知识口播、测评、vlog、种草。支持一次给 3-5 个选题备选 + 每个选题的完播/转化钩子设计。

  【真实触发话术】（直接复制发）
    你：帮我写一条抖音口红带货视频脚本，目标人群 18-25 女生，突出不掉色和性价比
    你：我是做职场干货的，给我 5 个这周能拍的选题，每个配 30 秒口播脚本

  【拿到什么 · 真实交付物】
    输出示例（节选）：
【选题】"百元内续航王？一天一充党狂喜"
【钩子 0-3s】"你们是不是也受够了半天就没电？"
【正文 3-25s】卖点1轻便…卖点2续航…卖点3快充…
【收尾 25-30s】"链接放左下，这价格闭眼入"
附：3 个备选标题 + 5 个标签
    （完整交付物以技能单独说明文件为准）

  【真实示例对话】
    你：帮我写一条抖音口红带货视频脚本，目标人群 18-25 女生，突出不掉色和性价比
    Agent：收到，我按你的平台和账号定位直接产出——（例如：输出示例（节选）：…）
    你：好，那按这个来。
    Agent：已生成，你可以照着进剪映执行；需要精细调整随时说。

  【常见问题 FAQ】
    Q：脚本太长剪不完？ A：先说总时长，我按"钩子+3卖点+收尾"压缩到对应秒数。
    Q：要不要分镜？ A：脚本已带镜头列，需要精细分镜用"分镜脚本拆解"技能。

  【适用场景】脚本分镜与文案策划 环节的标准化落地；适合个人创作者 / 带货团队 / 矩阵号。

  ── 2. 分镜脚本拆解 ──
  【所属分类】脚本分镜与文案策划
  【技能标识】storyboard-breakdown
  【一句话定位】把口播稿/脚本逐镜拆成可直接进剪映的"时间线结构"：镜号、景别、画面、台词、时长、运镜、素材来源。

  【详细概述】
    拿到脚本不会拆镜头？本技能把文字脚本转成一张标准分镜表（见 references/storyboard_template.md），每一镜都标注：景别（近/中/特/全）、画面内容、对应台词/字幕、时长（秒）、运镜方式、所需素材（主片/空镜/配音）。
    拆完的表就是你的剪辑施工图纸：粗剪时按镜号往时间线拖素材，不会漏镜也不会节奏乱。支持从"爆款选题与脚本生成"的输出直接续接。

  【真实触发话术】（直接复制发）
    你：把我刚写的口红脚本拆成 12 镜的分镜表，每镜标好时长和运镜
    你：这段口播稿帮我拆成剪映时间线结构，标注每镜素材来源

  【拿到什么 · 真实交付物】
    输出：标准分镜表（markdown 表格）
| 镜号 | 景别 | 画面内容 | 台词 | 时长 | 运镜 | 素材 |
| 1 | 近景 | 主播入画 | 今天拆一款… | 3s | 固定 | 主片 |
| 2 | 特写 | 细节 | 看这质感 | 4s | 推 | 空镜 |
    （完整交付物以技能单独说明文件为准）

  【真实示例对话】
    你：把我刚写的口红脚本拆成 12 镜的分镜表，每镜标好时长和运镜
    Agent：收到，我按你的平台和账号定位直接产出——（例如：输出：标准分镜表（markdown 表格）…）
    你：好，那按这个来。
    Agent：已生成，你可以照着进剪映执行；需要精细调整随时说。

  【常见问题 FAQ】

  ── 3. 口播文案生成与去AI味 ──
  【所属分类】脚本分镜与文案策划
  【技能标识】voiceover-copy-polish
  【一句话定位】生成自然口语化的口播文案，并自动做"去AI味"润色（去夸张象征、去破折号堆砌、去三段式套话），读起来像人说的话。

  【详细概述】
    很多 AI 写的口播稿"一看就是机器写的"：满篇破折号、夸张比喻、规则三段式。本技能分两步：先按你的卖点/人设生成口语稿，再用"去AI味"规则（详见 references 思路： inflated symbolism / 宣传腔 / 肤浅-ing分析 / 模糊归因 / 破折号滥用 / 三段式 / AI词汇 / 否定排比）逐句改写，让文案更像真人主播顺嘴说的。
    可单独使用（只润色你给的稿），也可接在脚本生成后做终稿打磨。

  【真实触发话术】（直接复制发）
    你：把我这段产品介绍改得口语一点，像主播对着镜头顺嘴说的
    你：这稿子AI味太重，帮我去AI味，保留卖点

  【拿到什么 · 真实交付物】
    输入稿："这款产品具有卓越的性能，首先…其次…最后…"
润色后："这玩意儿用起来是真顺手。开头我天天用，中间不卡，结尾还能…你懂我意思吧。"
    （完整交付物以技能单独说明文件为准）

  【真实示例对话】
    你：把我这段产品介绍改得口语一点，像主播对着镜头顺嘴说的
    Agent：收到，我按你的平台和账号定位直接产出——（例如：输入稿："这款产品具有卓越的性能，首先…其次…最后…"…）
    你：好，那按这个来。
    Agent：已生成，你可以照着进剪映执行；需要精细调整随时说。

  【常见问题 FAQ】
    Q：去AI味会改掉卖点吗？ A：只改表达，不改信息，关键参数原样保留。
    Q：能多口语？ A：可设"带货激情 / 朋友闲聊 / 专业讲解"三种语气。

  【适用场景】脚本分镜与文案策划 环节的标准化落地；适合个人创作者 / 带货团队 / 矩阵号。
  【门槛指引】🟢 零门槛
  【衔接上下游】分镜脚本拆解 → 本技能 → 剪映工程自动初始化

  ── 4. 剪映工程自动初始化 ──
  【所属分类】工程初始化与前置筹备
  【技能标识】jianying-project-init
  【一句话定位】按平台（抖音/小红书/B站/视频号）一键搭好剪映工程：画布比例、帧率、7 条标准轨道、素材槽位文件夹。

  【详细概述】
    本技能把"开剪映后一堆重复设置"变成标准化动作。你告诉它目标平台和账号，它产出一份工程初始化清单 + 可照做的步骤（见 references/jianying_init_guide.md）：建好 9:16/3:4/16:9 画布、30fps、7 条轨道（主视频/配音/配乐/音效/字幕/贴纸/封面）、并在工程旁建好素材槽位文件夹（主片/空镜/配音/配乐/字幕/贴纸/封面）。
    纯提示词 + 标准指引，不依赖任何外部付费服务，你在剪映里按清单点一遍即可，3 分钟搭好可复用的工程骨架。

  【真实触发话术】（直接复制发）
    你：帮我把这个工程按抖音 9:16 初始化，建好 7 条轨道和素材文件夹
    你：我要做小红书 3:4 的，给我一份剪映工程初始化步骤

  【拿到什么 · 真实交付物】
    输出：工程初始化清单 + 步骤
- 画布 1080×1920 / 30fps
- 轨道：主视频→配音→配乐→音效→字幕→贴纸→封面
- 素材文件夹：主片/空镜/配音/配乐/字幕/贴纸/封面

■ 第3.5章 08 自动剪辑(FFmpeg) 怎么用（真出片）
  08 类不是给你方案，而是直接调用你电脑上的 FFmpeg 出成片。适合：口播批量、混剪、矩阵号日更。

  第1步：确认 FFmpeg 已装
    打开终端/命令行，输入 ffmpeg -version，能看到版本号就算装好。
    没装的去 https://ffmpeg.org/download.html 下载 Windows builds，解压后把 bin 目录加入 PATH。

  第2步：安装任意 08 技能
    和其他技能一样：上传 ZIP → 发"请安装这个技能包" → 等 Agent 回复完成。
    08 技能 ZIP 里会多一个 scripts/ 文件夹，里面就是可运行的 Python 脚本。

  第3步：运行脚本
    以「自动成片流水线」为例，写一份 manifest.json：
    {
      "clips": ["素材/a.mp4", "素材/b.mp4"],
      "output_dir": "./成片",
      "resolution": {"w":1080, "h":1920},
      "fps": 30,
      "subtitle": false,
      "color_preset": "tongs",
      "platforms": ["douyin", "xhs", "bilibili"]
    }
    然后运行：
    python scripts/pipeline.py --manifest manifest.json
    几分钟后就得到：00_拼接成片 / 02_调色成片 / 各平台版本。

  也可以单步用：
    python scripts/prep_concat.py --input 素材文件夹 --output 拼接.mp4 --w 1080 --h 1920 --fps 30
    python scripts/auto_subtitle.py --input 成片.mp4 --output 带字幕.mp4 --transcribe
    python scripts/auto_color.py --input 成片.mp4 --output 调色.mp4 --preset tongs
    python scripts/export_platforms.py --input 成片.mp4 --outdir ./平台 --platforms douyin,xhs,bilibili,square

  ⚠️ 素材必须是你自有或 CC0 合规素材，禁止搬运他人视频。

■ 第4章 技能配合方案（三条线，你选）

  【线 A：剪映手动线】
  脚本分镜 →（产出脚本）→ 分镜拆解 →（分镜表）→ 工程初始化
  → 素材来源与合规获取 → 素材采集清单 → 素材导入打标 → 粗剪时间线 → 废片筛选
  → 节奏卡点 → 转场衔接 → 音频混音/降噪/踩点 → 字幕生成/美化
  → 特效包装/封面 → 调色 → 导出 → 多平台发布 → 数据复盘（回头部优化）

  【线 B：FFmpeg 自动执行线（这才是"真自动"）】
  01 口播文案 →（口播稿.txt）→ 08_方案→成片桥接器 →（字幕.srt）
  03 粗剪时间线 →（粗剪清单.txt）→ 08_方案→成片桥接器 →（manifest.json）
  04 节奏卡点 →（切点表）→ 08_方案→成片桥接器 →（切点.json）
  07 调色预设 →（中文名）→ 08_方案→成片桥接器 →（--preset 参数）
  → 08_自动成片流水线（拼接→字幕→调色→多平台导出）→ 多平台成片

  【线 C：剪映自动线（剪映党专属，半自动）】
  01-07 方案 → 08_方案→成片桥接器 →（manifest.json）
  → 09_剪映草稿自动生成 →（剪映草稿工程 xxx.draft）
  → 放进剪映草稿目录 → 打开即见排好的时间线 → 点导出出片
  （与线 B 共用同一份 manifest，方案层产出在剪映里也自动铺好，不用手动拖素材）

  三条线不是三选一，而是可切换：想精修用剪映线 A，想批量全自动用线 B，想剪映一键出片用线 C。

■ 第5章 常见问题 FAQ
  Q：要先学剪映吗？ A：01-07 不用全会，照清单点即可；08 会点命令行即可。
  Q：要买 API 吗？ A：不需要，本包零外部付费依赖。
  Q：08 类 FFmpeg 要付费吗？ A：FFmpeg 免费开源；whisper 本地模型免费。都不需要 API 密钥。
  Q：一条视频跑完要多久？ A：01-07 流程熟练后 30 分钟内；08 自动剪辑拼接/调色/导出几分钟一条。
  Q：多平台怎么发？ A：用「多平台发布适配」给各平台标题/标签/封面差异。
  Q：成片不好看怎么改？ A：用「数据复盘优化」定位问题，回对应环节重做。
  Q：素材从哪来？ A：用「素材来源与合规获取」，平台素材库/CC0图库/自拍清单，合规不搬运。
