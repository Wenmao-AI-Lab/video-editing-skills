======================================================
视频剪辑技能包工作流 · 技能汇总说明
（淘宝店：AI灵匣 整理）
======================================================

■ 这是什么
  一套覆盖「短视频剪辑全流程」的 AI Agent 技能包，共 29 个技能，
  按 9 大环节组织，从脚本分镜一路打通到自动剪辑（FFmpeg / 剪映双线）与多平台导出。
  01-07 类为提示词工作流（出方案），08 类为调用本地 FFmpeg 自动执行的脚本技能（真出片），
  09 类为调用 pyJianYingDraft 把同一份方案转成剪映草稿（半自动出片），
  中间用「方案→成片桥接器」把 01-07 的产出转成机器可读文件（srt / manifest），两线共用，
  全包零外部付费 API 依赖，装好即用、不报错。

■ 全流程闭环
  脚本分镜与文案策划 → 工程初始化与前置筹备 → 素材导入与粗剪
  → 精剪与节奏卡点 → 音频处理 → 字幕与画面包装 → 调色导出与发布复盘
  → 自动剪辑与批量导出(FFmpeg) / 剪映自动成片（同方案转剪映草稿）

■ 9 大环节 / 29 技能清单
  1. 脚本分镜与文案策划（3 个）
     · 爆款选题与脚本生成
     · 分镜脚本拆解
     · 口播文案生成与去AI味
  2. 工程初始化与前置筹备（3 个）
     · 剪映工程自动初始化
     · 素材采集清单与文件夹标准化
     · 素材来源与合规获取
  3. 素材导入与粗剪（3 个）
     · 素材自动导入与智能打标
     · 粗剪拼接时间线生成
     · 废片与重复片段智能筛选
  4. 精剪与节奏卡点（2 个）
     · 节奏卡点精剪
     · 转场与镜头衔接
  5. 音频处理（3 个）
     · 配音音效配乐混音
     · 降噪与音量标准化
     · 自动踩点配乐
  6. 字幕与画面包装（4 个）
     · 字幕自动识别生成
     · 字幕样式美化
     · 特效滤镜关键帧包装
     · 封面图与标题生成
  7. 调色导出与发布复盘（4 个）
     · 调色预设应用
     · 导出封装参数
     · 多平台发布适配
     · 数据复盘优化
  8. 自动剪辑与批量导出(FFmpeg)（6 个）——真出片
     · 素材批量预处理与拼接
     · 自动字幕识别与烧录
     · FFmpeg 自动调色与画质增强
     · 多平台尺寸自动导出
     · 自动成片流水线（串联）
     · 方案→成片桥接器（中间产物转换）← 把 01-07 的产出转成 08 能吃的文件

  9. 剪映自动成片（1 个）——半自动出片（剪映党专属）
     · 剪映草稿自动生成 ← 把 08 桥接器产出的同一份 manifest.json 转成剪映草稿工程，打开即见时间线

■ 依赖说明
  🟢 零门槛：纯提示词，Agent 推理即可产出（01-07 类）
  🟡 需本地安装剪映：仅「剪映工程自动初始化」需你本机装剪映客户端
  🟡 需本地安装 FFmpeg：08 类自动剪辑脚本调用 FFmpeg（免费开源），需本地安装并加入 PATH
  🟡 需本地安装 pyJianYingDraft：09 类剪映草稿生成调用 pyJianYingDraft（免费开源，仅写 JSON），pip install 即可
  🟡 字幕识别（可选）：08 类「自动字幕识别」使用本地 whisper（免费开源模型），首次会下载模型
  🔴 零外部付费 API：本包不绑定任何密钥接口，无密钥也能跑

■ 双线桥接架构（这才是这套包的核心）
  01-07 类产出方案，经 08_方案→成片桥接器落成同一份 manifest.json，向下分两条渲染线：
  · 剪映手动线：方案 → 你在剪映里照做 → 导出发布（适合精修/套模板）。
  · FFmpeg 自动执行线：manifest → 08_自动成片流水线直接出多平台成片（全自动、无界面）。
  · 剪映自动线（09 类）：manifest → 剪映草稿工程，打开即见排好的时间线，点导出出片（半自动、有界面）。
  桥接器让 01-07 不再只是"给人看的方案"，而是真能同时驱动两条执行线：
    · 01 口播稿.txt → script_to_srt.py → .srt（烧进视频，绕开 whisper）
    · 03 粗剪清单.txt → storyboard_to_manifest.py → manifest.json（pipeline 直接拼接）
    · 04 卡点表 → beatdetect.py → 切点.json（驱动自动转场/分段）
    · 07 调色预设名 → color_map.py → FFmpeg preset（自动调色）

■ 预期管理（很重要，先读）
  01-07 类：Agent 根据你的需求产出「方案 + 参数 + 清单 + 可直接照做的步骤」，你在剪映里照做。
  08 类（自动剪辑）：调用你本地 FFmpeg 直接产出成片文件——是真的"丢素材进去、多平台成片出来"。
  09 类（剪映草稿）：把 manifest 转成剪映草稿工程，你在剪映打开后点导出即出片——方案自动铺好时间线。
  ✅ 01-07 能自动产出：脚本/分镜/口播稿/卡点表/衔接表/字幕文本/调色参数/导出参数/发布清单/复盘模板
  ✅ 08 能自动产出：拼接成片 / 烧录字幕成片 / 调色成片 / 多平台尺寸成片
  ❌ 仍然不能自动做的：替你打开剪映在剪映里点按钮、真去网上下载别人视频、真生成一张封面图（封面是出构图与标题方案，出图需你配图或用图片工具）
  ⚠️ 08 类需要你自己安装 FFmpeg（免费开源）并加入 PATH，脚本会自动定位。
  ⚠️ 字幕识别（whisper）属于"可选但未实测"分支，推荐走桥接器把 01 口播稿转成 srt，准确率更高、无需下载模型。
  推荐节奏：先用 01-07 把"怎么剪"想清楚，再用桥接器把方案转成执行文件，最后用 08 把拼接/调色/导出等苦力活自动跑掉。

■ 怎么用
  1) 解压任意一个技能 ZIP 安装到技能目录（见新手手册「三步安装」）
  2) 对话里直接发指令，如："帮我写一条抖音口红带货脚本"
  3) 选路线：
     · 剪映手动线：按 01-07 顺序跑，产出在剪映里照做。
     · FFmpeg 自动线：01/03/04/07 产出后，用 08_方案→成片桥接器转成执行文件，再跑 08_自动成片流水线。
     · 剪映自动线：同样用桥接器转出 manifest，再用 09_剪映草稿自动生成转成剪映工程，打开即出片。
  4) 发布前用「多平台发布适配」和「数据复盘优化」收尾。
